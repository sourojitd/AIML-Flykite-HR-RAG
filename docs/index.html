01 · Overview

Policy answers employees can verify

A dense 14-page HR handbook creates ticket load and compliance risk when people guess. This project compares LLM-only, prompt-engineered, and RAG approaches — then sweeps six retrieval configs — so every answer can be traced to handbook evidence.

05 · Results

Retrieval is the dominant lever

Same three benchmark questions across methods. Combined score weights groundedness highest (0.40) for a compliance domain. Winner: C3-large+fewer.

Method / config Relevance Groundedness Fact coverage Combined
LLM only 0.765 0.489 0.244 —
Prompt engineering 0.505 0.597 0.122 —
RAG default (C1) 0.713 0.608 0.811 0.700
Tuned RAG C3 ★ 0.688 0.669 0.867 0.734

C3 uses 1200/250-character chunks, similarity search, k=3, MiniLM. With three scored queries, treat C3 as the selected prototype — not a proven global optimum.
